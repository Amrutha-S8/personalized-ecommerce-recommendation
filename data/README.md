# Data

This project uses the **Online Retail Dataset** from the UCI Machine Learning Repository.

- Official source: https://archive.ics.uci.edu/dataset/352/online+retail
- Kaggle mirror: https://www.kaggle.com/datasets/lakshmi25npathi/online-retail-dataset

Download `Online Retail.xlsx` and place it in this `data/` folder before running the notebook.
The raw file is intentionally not committed to this repository (see `.gitignore`) due to its size.
